GitHub Upload는 GitHub

에 파일을 빠르게 명령어 없이 업로드하기 위한 프로그램.


최신 버전 다운로드 (.exe)
최신 버전: v1.0.0 지원 OS: Windows 10/11 파일 크기: 53.2 MB

프로그램 소개

GitHub Upload은 복잡한 Git 명령어 없이 파일과 폴더를 GitHub에 저장소와 브랜치를 선택하고 버튼만 누르면 간편하게 업로드할 수 있습니다.

주요 기능

  • 파일 하나 및 여러 파일 업로드
  • 폴더 업로드
  • GitHub 저장소 및 브랜치 선택
  • 업로드 경로와 커밋 메시지 설정
